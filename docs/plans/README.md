## Conventions

- Plans describe sequence and gates, not canonical product requirements;
  durable decisions belong in [`../decisions/`](../decisions/).
- A plan that has been overtaken is deleted, not annotated. Git history keeps
  it; the tree keeps only what someone should act on.

## When to read

Before starting a delivery slice or re-running a validation gate.
