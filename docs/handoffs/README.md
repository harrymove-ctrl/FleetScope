# Handoffs

> **Historical handoffs:** B2 and the older Agent Viewer continuation prompts
> below target the superseded CASE-1042/Warden runtime. They are not the current
> demo plan. Use the active [Google runtime runbook](../design/hackathon-runtime.md)

Self-contained prompts and context packets for transferring FleetScope work to
another engineer or coding agent.

## Read this set

- [B2 live runtime and evidence handoff](b2-live-runtime-evidence.md) — next
  engineering task: close the real ADK, controlled-fault, Warden, idempotent
  retry, Cloud Run, and restart/replay evidence gate before visual polish.
- [Agent Viewer next-agent handoff](agent-viewer-next-agent.md) — current local
  Agent Viewer scope, contracts, validation commands, and stop conditions;
  read before taking over implementation.

## Conventions

- State the exact file scope, dependencies, acceptance criteria, validation
  commands, non-goals, and hand-back format.
- Keep handoffs time-bounded and evidence-based; update the source plan when
  requirements change.

## When to read

When continuing work from another session or preparing a task for a second
agent.
